# JapaneseClass

**ภาษาไทย** · [English](README.md)

เว็บฝึกภาษาญี่ปุ่นสำหรับทบทวนคันจิและคำศัพท์ด้วยตัวเอง มีคำอ่านและคำแปลภาษาไทย ใช้งานผ่านเบราว์เซอร์โดยไม่ต้องสมัครบัญชี

**หน้าเว็บ:** https://bkt-cmyk.github.io/JapaneseClass/

## โหมดฝึก

- **ฝึกเขียนคันจิ:** เขียนตามลำดับขีด ดูคำอ่านและความหมายภาษาไทย มีตัวอย่างลำดับขีด และแสดงตำแหน่งคำในชุดฝึก
- **ฝึกพิมพ์คำศัพท์:** ดูความหมายภาษาไทยแล้วพิมพ์คำอ่านภาษาญี่ปุ่น ตรวจคำตอบ ดูเฉลย หรือข้ามไปคำถัดไป

ข้อมูลฝึกเขียนมี 365 รายการ แบ่งเป็น 73 ชุดในระดับ N5/N4 ส่วนคำศัพท์มี 144 คำจากบทที่ 26–28

## วิธีเปิดบนเครื่อง

เปิดเซิร์ฟเวอร์ HTTP ในโฟลเดอร์หลักของโปรเจกต์:

```sh
python3 -m http.server 8000
```

จากนั้นเปิด http://localhost:8000 ในเบราว์เซอร์ ไม่แนะนำให้เปิดไฟล์ HTML ตรง ๆ ด้วย `file://` เพราะเบราว์เซอร์อาจบล็อกการอ่านไฟล์ JSON

## โครงสร้างโปรเจกต์

```text
index.html                     หน้าแรกและจุดเริ่มต้นของ GitHub Pages
pages/                         หน้าฝึกเขียนและฝึกคำศัพท์
assets/css/                    CSS ของแต่ละหน้า
assets/js/                     JavaScript ของแบบฝึก
data/                          ข้อมูลบทเรียน JSON
tests/                         ชุดทดสอบพื้นฐาน
archive/                       หน้าเขียนคันจิเวอร์ชันเก่า
kanji_practice.html            ลิงก์เก่า (เปลี่ยนเส้นทาง)
vocabulary_practice.html       ลิงก์เก่า (เปลี่ยนเส้นทาง)
README.md                      คู่มือภาษาอังกฤษ
```

โปรเจกต์ใช้ HTML, CSS และ JavaScript ธรรมดา ส่วนระบบเขียนคันจิอาศัย Hanzi Writer และข้อมูลลำดับขีดจาก jsDelivr จึงต้องเชื่อมต่ออินเทอร์เน็ตขณะฝึกเขียน

## ทดสอบ

```sh
node --test tests/smoke.test.mjs
```

ชุดทดสอบตรวจเส้นทางไฟล์ ข้อมูลบทเรียน ไวยากรณ์ JavaScript และการทำงานพื้นฐานของหน้าแบบฝึก แต่ยังควรทดลองใช้งานจริงในเบราว์เซอร์ด้วย
