# JapaneseClass

**ภาษาไทย** · [English](README.md)

เว็บฝึกภาษาญี่ปุ่นสำหรับทบทวนคันจิและคำศัพท์ด้วยตัวเอง มีคำอ่านและคำแปลภาษาไทย ใช้งานผ่านเบราว์เซอร์โดยไม่ต้องสมัครบัญชี

**หน้าเว็บ:** https://japaneseclass.vercel.app/

## โหมดฝึก

- **ฝึกเขียนคันจิ:** เขียนตามลำดับขีด ดูคำอ่านและความหมายภาษาไทย มีตัวอย่างลำดับขีด พร้อมบันทึก Progress และตำแหน่งบทเรียนในเบราว์เซอร์ โดยค่าเริ่มต้นจะไม่เลื่อนคำอัตโนมัติ (สามารถเปิดได้)
- **ฝึกพิมพ์คำศัพท์:** ดูความหมายภาษาไทยแล้วพิมพ์คำอ่าน ตรวจคำตอบ ดูเฉลย หรือข้ามคำ พร้อมแถบ Progress สรุปผลท้ายชุด และโหมดทบทวนคำที่เคยตอบผิด

ข้อมูลฝึกเขียนมี 365 รายการ แบ่งเป็น 73 ชุดในระดับ N5/N4 ส่วนคำศัพท์มี 144 คำจากบทที่ 26–28

## การบันทึกความก้าวหน้าและความเป็นส่วนตัว

Progress, ชุดที่เลือก, คำล่าสุด และรายการคำศัพท์ที่เคยตอบผิดจะถูกเก็บในเบราว์เซอร์ด้วย `localStorage` โดยไม่ต้องสมัครสมาชิก และไม่ส่งข้อมูลนี้ขึ้นเซิร์ฟเวอร์ ข้อมูลจะไม่ซิงก์ข้ามอุปกรณ์ และอาจหายหากล้างข้อมูลเว็บไซต์

เมื่อฝึกถึงท้ายชุด ปุ่ม **เริ่มชุดใหม่ (ล้าง Progress)** จะเริ่มนับคำที่สำเร็จใหม่เฉพาะชุดนั้น ส่วนประวัติคำศัพท์ที่เคยผิดจะยังอยู่จนกว่าจะทบทวนและตอบถูกในโหมดทบทวน หน้าคำศัพท์ยังมีคำแนะนำการเปิดแป้นพิมพ์ภาษาญี่ปุ่นบนมือถือและคอมพิวเตอร์

## วิธีเปิดบนเครื่อง

เปิดเซิร์ฟเวอร์ HTTP ในโฟลเดอร์หลักของโปรเจกต์:

```sh
python3 -m http.server 8000
```

จากนั้นเปิด http://localhost:8000 ในเบราว์เซอร์ ไม่แนะนำให้เปิดไฟล์ HTML ตรง ๆ ด้วย `file://` เพราะเบราว์เซอร์อาจบล็อกการอ่านไฟล์ JSON

## โครงสร้างโปรเจกต์

```text
index.html                     หน้าแรกของเว็บไซต์ Static บน Vercel
pages/                         หน้าฝึกเขียนและฝึกคำศัพท์
assets/css/                    Theme กลางและ CSS ของแต่ละหน้า
assets/js/                     JavaScript ของแบบฝึก
data/                          ข้อมูลบทเรียน JSON
tests/                         ชุดทดสอบพื้นฐาน
archive/                       หน้าเขียนคันจิเวอร์ชันเก่า
README.md                      คู่มือภาษาอังกฤษ
```

ทุกหน้าใช้ดีไซน์ร่วมกันผ่าน `assets/css/theme.css` โดยยึดหน้าฝึกเขียนคันจิเป็นต้นแบบ ทั้งพื้นหลังสีครีม สีเขียว Teal ปุ่ม Coral การ์ด และฟอนต์ หน้าเว็บปรับรูปแบบตามขนาดหน้าจอทั้งมือถือและคอมพิวเตอร์ และรองรับการพิมพ์ภาษาญี่ปุ่นผ่าน IME โดยไม่ตรวจคำตอบระหว่างเลือกตัวอักษร โปรเจกต์ใช้ HTML, CSS และ JavaScript ธรรมดา ส่วนระบบเขียนคันจิอาศัย Hanzi Writer และข้อมูลลำดับขีดจาก jsDelivr จึงต้องเชื่อมต่ออินเทอร์เน็ตขณะฝึกเขียน

## ทดสอบ

```sh
node --test tests/smoke.test.mjs
```

ชุดทดสอบตรวจเส้นทางไฟล์ ข้อมูลบทเรียน ไวยากรณ์ JavaScript การบันทึก Progress การตรวจคำตอบ การทบทวนคำผิด การจบบทเรียน ระบบสำรองเมื่อโหลดไม่ได้ และการทำงานพื้นฐานของหน้าแบบฝึก แต่ยังควรทดลองใช้งานจริงในเบราว์เซอร์ด้วย
